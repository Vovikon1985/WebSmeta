### IMP-001: Просмотр DWG внутри приложения

| Поле | Значение |
|------|----------|
| **ID** | IMP-001 |
| **Название** | Просмотр DWG внутри приложения |
| **Приоритет** | 🟡 Средний |
| **Статус** | 💡 Идея |
| **Целевая версия** | — |
| **Создано** | 2026-08-13 |
| **Обновлено** | 2026-08-13 |

**Описание**:
Интеграция компонента для просмотра DWG-файлов непосредственно в окне приложения без необходимости открытия AutoCAD. Пользователь сможет просматривать чертежи, находить метки, проверять привязки к объектам.

**Мотивация**:
- Ускоряет работу с исполнительной документацией
- Не требует запуска AutoCAD для простого просмотра
- Позволяет просматривать метки и их привязки

**Технические варианты**:
1. **Autodesk Viewer API** (облачный) — требует интернета, может не подходить для 100% локального приложения
2. **ODA Drawings SDK** (Open Design Alliance) — платный, требует лицензии
3. **LibreDWG** — открытый, но ограниченная поддержка DWG
4. **AutoCAD ActiveX / COM Automation** — требует установленного AutoCAD, но позволяет отображать чертежи
5. **Собственный рендерер** — очень сложно, не рекомендуется

**Ограничения**:
- Большинство решений либо платные, либо требуют AutoCAD
- Может значительно увеличить размер приложения
- Может усложнить архитектуру

**Зависимости**:
- Требует анализа доступных бесплатных компонентов
- Требует оценки лицензионных ограничений

**Заметки**:
Реализация возможна только после основного релиза. Требует отдельного исследования.

## 🔄 Правила работы с бэклогом

### Приоритизация
1. Новые идеи всегда добавляются со статусом **💡 Идея**
2. Приоритет определяется пользователем или по согласованию
3. Статус меняется на **📅 Запланировано** только после явной команды пользователя
4. Статус меняется на **🚧 В работе** только при начале реализации
5. Статус меняется на **✅ Завершено** после успешной реализации и тестирования

### Запреты
- ❌ **НЕ реализовывать** улучшения автоматически
- ❌ **НЕ менять** статус без явной команды пользователя
- ❌ **НЕ удалять** улучшения без явной команды пользователя
- ❌ **НЕ смешивать** улучшения с текущими задачами этапов

### Связь с этапами
- Улучшения **НЕ входят** в этапы 0-14
- Улучшения реализуются **после** основного релиза или в отдельных версиях
- Если улучшение становится критичным, оно может быть включено в план как отдельный этап
