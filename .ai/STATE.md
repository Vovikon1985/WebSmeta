## 📋 Следующие задачи (после завершения текущего этапа)

### Приоритет 1 (критичные)
1. **Получить реальный XML ГРАНД-Сметы от пользователя**
   - Файл должен быть помещён в `.ai/XML_SPEC.md` или в отдельный файл `docs/sample-estimate.xml`
   - Необходимо определить: namespace, элементы, атрибуты, иерархию, идентификаторы

2. **Определить версию AutoCAD пользователя**
   - Требуется для выбора целевого фреймворка Plugin
   - AutoCAD 2024 и ниже → .NET Framework 4.8
   - AutoCAD 2025+ → .NET 8.0

### Приоритет 2 (важные)
3. **Создать DATABASE.md** на основе ER-модели из ARCHITECTURE.md
4. **Создать AUTOCAD_INTEGRATION.md** с деталями работы с AutoCAD API
5. **Создать DEVELOPMENT.md** с инструкциями по сборке и запуску

### Приоритет 3 (подготовительные)
6. **Подготовить переход к Этапу 1**: создать команды `dotnet new` для генерации Solution
7. **Проверить доступность NuGet-пакетов**: Dapper, Microsoft.Data.Sqlite, Microsoft.Extensions.DependencyInjection

## 📦 Принятые архитектурные решения

| # | Решение | Обоснование | Дата принятия |
|---|---------|-------------|---------------|
| ADR-001 | Использовать Named Pipes для IPC между App и AutoCAD Plugin | Простота, надёжность, локальность, не требует сетевых портов | 2026-08-13 |
| ADR-002 | Использовать Dapper вместо EF Core для доступа к SQLite | Лучшая производительность для больших смет, контроль над SQL, простота bulk-операций | 2026-08-13 |
| ADR-003 | Использовать собственные SQL-миграции вместо EF Core Migrations | Проще, надёжнее, нет лишней зависимости от EF Core | 2026-08-13 |
| ADR-004 | WinForms App на .NET 8.0 | Быстрее и стабильнее .NET Framework, современная поддержка | 2026-08-13 |
| ADR-005 | Contracts на .NET Standard 2.0 | Совместимость и с .NET 8, и с .NET Framework 4.8 | 2026-08-13 |
| ADR-006 | Domain и Application на .NET Standard 2.0 | Максимальная переносимость, независимость от рантайма | 2026-08-13 |
| ADR-007 | Использовать Handle вместо ObjectId для устойчивой идентификации объектов AutoCAD | Handle сохраняется в DWG, ObjectId меняется между сессиями | 2026-08-13 |
| ADR-008 | Использовать VirtualMode в DataGridView для больших смет | Невозможно загрузить 50 000+ строк в память UI | 2026-08-13 |
| ADR-009 | Использовать Microsoft.Extensions.Logging + собственный FileLogger | Бесплатно, стандартно, достаточно для локального приложения | 2026-08-13 |
| ADR-010 | Использовать Result Pattern вместо исключений для ожидаемых ошибок | Явная обработка ошибок, тестируемость | 2026-08-13 |
