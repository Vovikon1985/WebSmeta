# XML Specification (Grand Smeta / External Sources)

*Здесь будет размещен пример реального XML экспорта из программы Гранд-Смета или другого сметного ПО.*

## Required Fields Mapping
- Шифр позиции -> `Code`
- Наименование -> `Name`
- Ед. изм. -> `Unit`
- Объем (начальный) -> `InitialVolume`
- Цена единицы -> `UnitPrice`
- Всего -> `TotalSum`
